# A48–A52：routed expert top-k 初筛

## 结论

在 Raspberry Pi 5、4 GiB、4 线程、无 swap 的单轮 `pp4/tg1` 初筛中，修复图形状后的
top-8 相对原始 top-10，Prefill 从 `0.046178` 提高到 `0.0542854 t/s`（`+17.56%`），
Decode 从 `0.0265563` 提高到 `0.0293539 t/s`（`+10.53%`），wall time 从 `546 s`
降到 `528 s`（`-3.30%`）。方向与少算、少读 20% routed experts 一致，但每项只有一轮，
不能据此设为默认。

质量探针也不能用于推广。A51 top-8 和 A52 原始 top-10 对同一道红蓝球问题都回答
`50%`，而正确答案是 `46.67%`。因此 A51 的错误不能单独归因于 top-8，但这个问题也没有
区分两种配置的能力。下一步使用固定 ARC-Challenge 多项选择子集比较 top-10、top-8 和低比特
模型，top-8 在此之前保持 opt-in。
