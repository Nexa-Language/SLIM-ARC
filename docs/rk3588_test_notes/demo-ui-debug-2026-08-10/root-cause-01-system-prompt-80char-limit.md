# 根因分析: 系统提示"控制在 80 字以内"导致模型拒绝长输出

## 日期: 2026-08-10

## 根因描述
index.html:468 的系统提示包含"控制在 80 字以内"，直接指示模型将回答限制在 80 字以内。
当用户请求长文本生成时，模型遵循系统提示，主动拒绝或缩短输出，导致"输出一段就停"。

## 证据链

### 证据1: 前端代码 (index.html:468, 修复前)
```javascript
{ role: 'system', content: '你是 SLIM-ARC 优化后的端侧 AI 助手。...请简洁友好地回答用户问题，控制在 80 字以内。' },
```

### 证据2: 后端直连消融 (前端参数)
- 请求: "请写一篇较长的文章，至少200字" + 系统提示含"80字以内"
- 响应: "我无法写长文，但可以帮你精简内容或提供简要回答。你需要什么帮助？"
- finish_reason: "stop" (模型主动停止，非截断)
- 输出仅 96 字符

### 证据3: 后端直连消融 (宽松参数)
- 请求: 同上，但系统提示改为"请详细回答问题"
- 响应: 完整的 1690 字文章
- finish_reason: "stop" (自然结束)

### 证据4: "强制生成500字"场景
- 请求: "强制生成500字" + 系统提示含"80字以内"
- 响应: "我无法生成500字内容，您的问题可能需要更详细的说明或调整需求。"
- 模型明确拒绝长输出

### 证据5: /slots 数据
- slot 3: n_decoded=18, n_remain=182, has_next_token=false
- 模型仅生成 18 token 就停止，200 个 max_tokens 额度中还有 182 个未使用
- 证明是模型主动停止，不是 max_tokens 截断

## 结论
系统提示"控制在 80 字以内"是"输出一段就停"的**主要根因**。
模型严格遵循系统提示，在用户请求长输出时主动拒绝或极简化回答。
