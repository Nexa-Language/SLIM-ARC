结论（结构事实）
-------------------------------------------------------------------------------
1. 左栏 = .chat（行 250/264）内部 .chat-messages#messages（行 254）。
   .chat-messages 类仅出现于行 73(CSS) 与行 254(HTML)，唯一归属 = 左侧聊天区。
2. 右栏 = .monitor#monitor（行 267），overflow-y:auto 自带（行 138）。
3. .main 高度固定(calc(100vh-56px))，但 grid-template-rows 默认 auto；
   .chat 是 grid item 且 overflow:visible、无 min-height（默认 auto）。
   => 关键风险点：.chat 的自动最小尺寸可能把 grid 行撑高，
      使 .chat-messages 的 flex:1+overflow-y:auto 因高度充足而不触发滚动。
