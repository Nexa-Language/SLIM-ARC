5. 上游跟踪配置（辅助修正）
----------------------------------------------------------------
背景：push 成功后 `git branch --set-upstream-to=origin/haoma` 失败，
根因：.git/config 的 remote.origin.fetch 仅含 main 分支
（fetch = +refs/heads/main:refs/remotes/origin/main），
未包含 haoma，本地无 refs/remotes/origin/haoma 远程跟踪引用。

处理（git 配置调整，非功能代码）：
  git config --add remote.origin.fetch "+refs/heads/haoma:refs/remotes/origin/haoma"
  git fetch origin
  → * [new branch] haoma -> origin/haoma

结果：
  git rev-parse @{u}        → origin/haoma（上游已生效）
  git status -sb            → ## haoma...origin/haoma（本地与远程同步）
  git log --oneline -1 origin/haoma → c22dcad（与本地一致）
