## 文献提取的关键思路（与 RK3588 CPU-only 相关）

1. **先做可观测**：`wasted bytes / saved stall / hit rate` 三指标；先可观测再优化。
2. **按置信度区分 prefetch**：高置信度才预取/commit，低置信度回退（CommitMoE / DALI）。
3. **调度隐藏 I/O / admission control**：把专家预取纳入统一 I/O 预算，防止突发抢占（MoE-Lightning / CrossPool）。
4. **Cache/预测提升**：temporal + 热门专家（ReMoE locality / DALI workload-aware / LRU-K 思路）。

## 改进 1（阶段 11）：专家预取可观测性指标（foundation）

- **文献依据**：结论摘要 4 + "先做可观测的 memory hierarchy runtime" + 必须建立指标（expert cache hit rate、wasted prefetch bytes、miss stall）。
- **实现**：`prefetch_scheduler` 增加运行时统计
  - `expert_prefetch_bytes`：实际 WILLNEED 下发的专家字节
  - `expert_hit_bytes`：预取且下一 token 实际被使用的专家字节
  - `expert_waste_bytes`：预取但未使用的专家字节
  - `router_samples`：统计采样数
  - 析构时 `dump_metrics()` 输出汇总；命中率 = hit/(hit+waste)
- **测试**：短/长生成运行，确认指标输出且自洽（prefetch = hit + waste）。

## 改进 2（阶段 12）：置信度门控专家预取（减少无效 WILLNEED）

- **文献依据**：结论摘要 4（按置信度区分 prefetch）+ CommitMoE 高置信度才 commit。
- **实现**：`cache_router_experts` 维护 2-token 路由历史（cached=上一步、prev=上两步）；
  `issue_expert_willneed` 在 `SLIM_ARC_EXPERT_CONF=1` 时仅对 **连续两 token 都激活** 的专家下发 WILLNEED（稳定=高置信度），低置信度不浪费 I/O、依赖按需分页。
- **预期**：hit rate 上升、waste bytes 下降；RK3588 解码（非 I/O 受限）速度应中性或微升。
- **测试**：A/B 解码 t/s + 指标对比（改进 1 的 hit/waste）。

## 改进 3（阶段 13）：专家预取纳入统一 I/O 预算（admission control）

- **文献依据**：结论摘要 3（调度隐藏 I/O）+ 技术手段 5（admission control：按 expert cache/KV budget 限流）。
- **实现**：
  - `prefetch_scheduler` 增加 `expert_budget_`（0=不限），`set_expert_budget()` 设置。
  - `unified_io_scheduler::tick()` 在 `SLIM_ARC_EXPERT_BUDGET=1` 时把 `budget.expert_bytes` 下发到 prefetch scheduler。
  - `issue_expert_willneed` 按预算截断单步 WILLNEED 字节，防止 ~959MB 全层突发抢占 I/O。
- **测试**：A/B 解码 t/s + 单步预取字节是否被截断、hit rate 变化。

## 改进 4（阶段 14）：组合预测器（temporal + 热门专家）

- **文献依据**：ReMoE（提高 expert reuse/locality）+ DALI（workload-aware cache）+ 技术手段 3（LRU-K/workload-aware）。
- **实现**：`cache_router_experts` 按层累加专家激活频次（`expert_pop_counts_`）；
  `SLIM_ARC_EXPERT_POP=K` 时 `issue_expert_willneed` 取 **temporal 预测 ∪ 该层 top-K 热门专家** 并集下发。
- **预期**：hit rate 提升（覆盖更广）、miss 减少；字节数增加。
- **测试**：A/B 解码 t/s + hit rate/waste 对比（与 baseline、改进 2 对照）。
