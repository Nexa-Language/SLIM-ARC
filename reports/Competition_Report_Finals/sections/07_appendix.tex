\subsection{证据等级与比较规则}

为同时保存研发过程和可用于结论的结果，本附录将实验划分为四类。A 类具有明确合同、重复或终态复核以及完整证据链；B 类来自真实运行，但样本较少或只验证单一机制；C 类存在链接错误、控制变量错误、跨缓存拼接或已被后续实验推翻，仅用于研发追溯；D 类证明构建、运行或硬件枚举，不代表目标加速路径。

所有 Prefill/Decode 均以 token/s 表示。提升率只在同设备、同模型、同缓存状态、同资源限制和同 workload 内计算。cold 与 warm、Q4\_K\_M 与 IQ4\_XS、CPU-only 与 NPU、cgroup peak 与进程 RSS 均不直接相除。表中未给出方差的单次结果只用于趋势或机制解释。
